# Sticker Studio — صانع ملصقات واتساب

تطبيق أندرويد (Kotlin + Jetpack Compose) لصناعة حزم ملصقات واتساب الثابتة والمتحركة وإضافتها مباشرة إلى واتساب / واتساب للأعمال.

> **حالة المشروع:** الكود مكتوب بالكامل، لكن لم يُبنَ APK بعد. راجع [`PROJECT_STATUS.md`](PROJECT_STATUS.md) لمعرفة ما تم التحقق منه فعليًا وما لم يُتحقق منه.

## المميزات
- حزم متعددة (قاعدة Room)، 3–30 ملصق، مسودات، ترتيب/حذف/استبدال، معاينة.
- محرر: قص/تكبير/تدوير/قلب، إزالة الخلفية (تلقائي على الجهاز + ممحاة يدوية)، شفافية، حد، ظل، نص وإيموجي وأشكال ورسم، تراجع/إعادة.
- ملصقات متحركة من GIF/فيديو إلى WebP متحرك (512×512، ≤10 ثوانٍ، ≤500 ك.ب) مع شريط تقدم وإلغاء.
- تصدير عبر واجهة واتساب الرسمية (ContentProvider + `ENABLE_STICKER_PACK`) مع فحص قبل الإرسال. ملف ZIP نسخة احتياطية فقط.
- مُحدِّث من GitHub Releases: فحص، تنزيل بنسبة تقدم، تحقق SHA-256 والحزمة والتوقيع، ثم التثبيت عبر مثبّت أندرويد (لا تثبيت صامت).
- صورك لا تُرفع لأي خادم. الصلاحيات: الإنترنت (للتحديث) وطلب التثبيت فقط.

## البناء
المتطلبات: JDK 17 وAndroid SDK 35.
```bash
./gradlew testDebugUnitTest
./gradlew assembleDebug -PUPDATE_REPO_OWNER=<حسابك> -PUPDATE_REPO_NAME=StickerStudio
```
أو ببساطة ارفع المشروع إلى GitHub ودع **Actions** تبني (`build.yml`).

## الإصدارات والتحديث فوق القديم
اقرأ [`docs/RELEASING.md`](docs/RELEASING.md): إنشاء مفتاح التوقيع، النسخ الاحتياطي، أسرار GitHub، ورفع إصدار جديد بوسم `vX.Y.Z`.
القواعد الثابتة: `applicationId` لا يتغير، نفس مفتاح التوقيع دائمًا، و`APP_VERSION_CODE` يزيد في كل إصدار.
